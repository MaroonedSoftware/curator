# @curator/web

Browser UI over [`@curator/api`](../api/README.md): Vite, React 19, Mantine, TanStack Router and
TanStack Query, laid out like `ats/apps/web`.

## Running

```
pnpm --filter @curator/api dev   # the API on :14100
pnpm --filter @curator/web dev   # this app on :14102
```

Vite proxies `/api` to the API and strips the prefix, so the browser stays same-origin. A
production deployment needs the same: the API reachable at `/api` on the app's origin.

## Layout

```
src/
  main.tsx               providers and the router
  api/                   api.client.ts (typed fetch over every API route), query options and keys
  routes/                TanStack file routes; routeTree.gen.ts is generated by the Vite plugin and committed
  components/            pages and pieces, one folder per area
tests/
  fake.api.ts            stubs fetch with a table of "METHOD /path" responders
  test.render.tsx        renders the real route tree at a path under the app's providers
```

TV failures surface as the API reports them (`src/api/api.error.ts`): unreachable, didn't answer,
refused, or rejected.
